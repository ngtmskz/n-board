GETTING STARTED

はじめかた

インストールは不要です。ブラウザ（Chrome をおすすめします）で開くだけで使えます。

開いてログイン

N-Board を開き、Google でログイン を押します。組織の Google アカウントでのみ利用できます。

ボードを作る

＋ 新しいボード を押すと、新しいボードが開きます。左上のタイトルを押すと名前を変えられます。

リンクを共有

右上の 共有 から リンクをコピー して、Slack などで参加者に送ります。

みんなで書く

キャンバスをダブルクリックすると付箋ができます。誰かが書いた内容は、すぐに全員の画面に出ます。

トップ画面には「参加しているボード」が並びます。一度開いたボードは、ここからいつでも開き直せます。ボード名で探すこともできます。

TOOLS

ツールバーの道具

左のツールバーから道具を選んで、キャンバスをクリックすると置けます。ボタンにマウスを乗せると、使い方が出ます。Esc でいつでも「選択」に戻ります。

選択 V

付箋などを選んで、動かしたり、色を変えたりします。ふだんはこの状態で使います。

画面移動 H

どこをドラッグしても画面だけが動きます。付箋をうっかり動かしたくないときに。

付箋

クリックした場所に付箋を置きます。ボタンを押すと横に出るパネルで「正方形」と「横長」を選べます。キャンバスをダブルクリックしても置けます。

テキスト

背景のない文字。お題や見出しに。大きさは 小・中・大・特大 の4段階、色も変えられます。

セクション

付箋をまとめる枠。ドラッグで範囲を決めます（クリックなら標準の大きさ）。見出しをつかむと、中の付箋ごと動きます。

矢印 L

付箋・テキスト・画像をつなぎます。始まりをクリック → 先をクリック。何もないところで離すと、つないだ先に同じ付箋ができます。

画像

ファイルを選んで貼ります。command ⌘+V（Windows は Ctrl+V）やドラッグ＆ドロップでも貼れます（PNG・JPEG・GIF・WebP、10MB まで）。

スタンプ

👍 ❤️ ⭐ 💯 🔥 💡 🤣 👀 ❓ と、自分の顔。押すとぴょこっと動きます。付箋に付くので、投票の集計にも使えます。

コメント C

付箋を押すと、その付箋にコメントを書けます。続けて別の付箋にも書けます。

元に戻す・やり直し

自分の操作だけを取り消します。ほかの人の操作は取り消されないので、安心して戻せます。

HOW TO

操作のコツ

知っておくと、ぐっと速く書けるようになる操作です。

付箋を書く・増やす

  • キャンバスをダブルクリックすると付箋ができて、すぐに書けます。書き終わったら Esc か、ほかの場所をクリック。
  • 付箋を選ぶと上下左右に ＋ が出ます。押すと、隣に同じ色の付箋ができて続けて書けます。
  • 選んだときに出るパネルで、色（7色）・形（正方形／横長）を変えられます。次に置く付箋は、最後に選んだ色になります。
  • 付箋の文字の中の URL は、押せるリンクになります。

スタンプとコメント

  • スタンプは、押した場所にある付箋に付きます（付く先の付箋が青く光るので、押す前にわかります）。付箋を動かせば一緒に動きます。
  • 投票にそのまま使えます。どの付箋に何個押されたかが記録されるので、CSV で書き出せば付箋ごとの票数がすぐにわかります。スプレッドシートで「スタンプ合計」の列を並べ替えれば、人気の順に並びます。
  • スタンプを選んで Delete で取り消せます。
  • コメントがある付箋には 💬 と件数が出ます。押すと付箋の横にパネルが開きます。Enter で送信、Shift+Enter で改行。
  • コメントを直せるのは書いた本人だけ。消せるのは本人とボードの作成者です。

選ぶ・動かす・そろえる

  • 何もないところからドラッグすると、範囲で選べます。Shift＋クリックで選択に足す・外す。command ⌘+A（Windows は Ctrl+A）で全部。
  • 動かしていると、近くの付箋と端や中心がそろう位置に吸い付き、点線が出ます。吸い付かせたくないときは command ⌘（Windows は Ctrl）を押しながら。
  • Shift を押しながら動かすと、真横か真下にだけ動きます。
  • option ⌥（Windows は Alt）を押しながらドラッグすると複製。command ⌘+D（Windows は Ctrl+D）でも複製できます。

画面を動かす・拡大する

  • トラックパッド：2本指でスライドして移動、ピンチで拡大・縮小
  • マウス：ホイールで移動、command ⌘（Windows は Ctrl）を押しながらホイールで拡大・縮小
  • どのツールでも：Space を押しながらドラッグで移動
  • 迷子になったら：右下の （全体を表示）でボード全体が入ります

コピー＆ペーストで、ボードからボードへ

選んだものを command ⌘+C（Windows は Ctrl+C）でコピーし、別のボードで command ⌘+V（Windows は Ctrl+V）で貼れます。前回のふりかえりの枠を使い回すときに便利です。セクションをコピーすると中の付箋も一緒に入ります（スタンプとコメントは入りません）。Slack などに貼ると、付箋の文字が1行ずつ並びます。

SHARING

共有する

右上の「共有」から、誰がボードを開けるかを選び、リンクをコピーします。

共有範囲は2種類

リンクを知っている組織のメンバー初期の設定。リンクを知っていれば、組織の人は誰でも参加できます。
招待した人だけ名前かメールアドレスで招待した人だけが開けます。リンクが広まっても、招待していない人は開けません。

共有範囲の変更と招待は、ボードを作った人だけができます。

🔒 組織の人だけで使えます

  • ログインできるのは組織の Google アカウントだけです。組織の外の人はボードを開けません。
  • ボードの一覧は誰にも見えません。リンクを知らなければ、ボードにはたどり着けません。
  • 付箋は参加者なら誰でも動かせ、消せます（消しても「元に戻す」で戻せます）。
  • ボードそのものを削除できるのは、作った人だけです。削除すると元に戻せません。

FAQ

よくある質問

組織の外の人を招待できますか？
できません。ログインできるのは組織の Google アカウントだけです。組織の外の方とのワークショップでは、書き出した画像や HTML を共有してください。
同じ付箋を同時に書き換えたらどうなりますか？
後から書いた方の内容が残ります。ふだんは自分の付箋を書くことが多いので、ほとんど気になりません。
間違えて付箋を消してしまいました
「元に戻す」で戻せます。キーボードなら command ⌘+Z（Windows は Ctrl+Z）です。戻せるのは自分の操作だけで、ページを再読み込みすると戻せる履歴は消えます。ほかの人が消した付箋は、消した本人に戻してもらってください。
ボードを消したいです
ボード名の横の メニューの「ボードを削除」から削除できます。削除できるのはボードを作った人だけで、元に戻せません。
タイマーや BGM の音が鳴りません
ブラウザの決まりで、ページを一度もクリックしていないと音が出ません。🎵 ボタンに赤い印が出ているときは、押すと音が出るようになります。音量が 0 になっていないかも確かめてください。
iPad などのタブレットでも使えますか？
タッチ操作に対応しています。1本指のドラッグで画面の移動、2本指のピンチで拡大・縮小します。複製などはボタンからも操作できます。
英語で表示できますか？
ブラウザの言語が日本語以外なら英語で表示されます。トップ画面のアカウントのメニュー（またはログイン画面の下）の「表示言語」で切り替えることもできます。
