# 設計メモ

## 構成

```
src/
  config.ts            環境ごとの設定（.env から）
  firebase.ts          Firebase の初期化とエミュレーター接続
  auth.ts              ログイン・ユーザー情報
  types.ts             データ構造の型（Firestore のドキュメントと対応）
  constants.ts         色・スタンプの定義、書き込み間隔などの調整値
  data/                Firestore の読み書き（画面から直接 Firestore を触らない）
  board/
    store.ts           ボード画面の状態（Firestore の状態＋手元の未確定の変更）
    actions.ts         操作（作成・削除・色の変更など）。書き込みと「元に戻す」の記録をまとめて行う
    undo.ts            元に戻す／やり直し
    geometry.ts        セクションの所属判定、スタンプの位置計算
    snap.ts            ドラッグ中の吸着と、「＋」で足す付箋の位置の計算
    Canvas.tsx         キャンバス（移動・拡大縮小・ドラッグ）
    BoardObjects.tsx   付箋・セクション・スタンプの表示と文字編集
  pages/               ログイン画面・履歴画面
firestore.rules.template  セキュリティルール（許可ドメインを埋め込んで firestore.rules を生成）
tests/rules.test.ts       セキュリティルールのテスト
```

## データ構造

```
boards/{boardId}
  title, ownerUid, ownerName, visibility('link'), createdAt, updatedAt, schemaVersion

boards/{boardId}/objects/{objectId}     付箋・セクション・スタンプ・テキスト・画像・矢印を type で区別
  共通: type, x, y, z, createdBy{uid,name,photoURL}, createdAt, updatedBy, updatedAt, deleted, locked
  sticky:  w, h, text, color, parentId（所属セクション）
  section: w, h, title, color
  text:    w, h, text, fontSize(16/24/36/56), color, autoWidth, parentId（所属セクション）
           autoWidth=true なら文字に合わせて横に伸びる（上限 800px）。false（古いデータは項目なし）なら w で折り返す
           w・h は表示上の大きさ。文字・大きさ・幅を変えた人の画面で測って保存する
  stamp:   stampKind, targetId（押した先の付箋・セクション。null ならボード）
           x, y は targetId があればその左上からの相対位置
  image:   w, h, src（Storage の置き場所）, parentId（所属セクション）
  connector: fromId, toId（つなぐ2つ。付箋・テキスト・画像・セクション）, label（添えるテキスト。50文字まで）, bothEnds（両向きか。ない古い矢印は片向き）
           位置は両端から決まるので x, y は使わない（常に 0）

boards/{boardId}/comments/{commentId}   付箋へのコメント
  targetId（付箋）, text（1〜1000文字）, createdBy{uid,name,photoURL}, createdAt, updatedAt, edited, deleted
boards/{boardId}/presence/{uid}         name, photoURL, lastSeen
boards/{boardId}/state/timer            status(idle/running/paused), durationMs, remainingMs, startedAt, updatedBy, updatedAt
boards/{boardId}/state/bgm              trackId(relax/focus/happy/groove または null), updatedBy, updatedAt
users/{uid}/history/{boardId}           title, ownerUid, lastOpenedAt, stickyCount, commentCount（最後に開いていたときの数）
```

- ボードIDとオブジェクトIDは Firestore の自動ID（20文字の乱数）。ルールでも20文字以上を必須にしている
- ボードは `get` のみ許可し、一覧取得（`list`）は禁止している
- 存在しないボードを `get` すると「存在しない」が返る（削除済みの表示に使う）
- スキーマを変えるときは `boards.schemaVersion` を上げ、古いボードを読むときの変換を `data/` に入れる。

## 主な設計判断

### オブジェクトは1つのコレクションにまとめる

付箋・セクション・スタンプを `objects` にまとめ、`type` で区別している。画面は1つのコレクションを監視するだけで済み、元に戻す・削除・将来のロックや書き出しも共通の処理で扱える。新しい種類は `type` を増やし、ルールの `validObject` に検証を足せば追加できる。

### 削除は論理削除（deleted: true）

参加者は誰の付箋でも削除できる。物理削除すると「元に戻す」で作り直す必要があり、そのとき作成者を本人以外にすることをルールで許すと作成者を偽れてしまう。論理削除なら作成者情報を保ったまま復活できる。物理削除はボード削除時の後片付けのみで、ボード作成者だけが行える。

### 元に戻すは画面側で記録する

自分の操作だけを、この画面の中で「項目の変更前・変更後」として記録する（作成は `deleted: true → false`、削除は `false → true`）。他の人の操作は記録しないので、元に戻しても他の人の操作は取り消されない。ページを再読み込みすると履歴は消える。

### 同時編集とドラッグ

- 同じ付箋を同時に編集した場合は、後から書いた方が残る（項目単位）
- ドラッグ中は手元の表示を即座に動かし、Firestore には `DRAG_WRITE_INTERVAL_MS`（250ms）ごとに書き込む。手を離した位置は必ず書き込む
- 書き込み後、Firestore から同じ値が届くまでは手元の値を表示し続ける（表示が一瞬戻るのを防ぐ）
- 作成したオブジェクトは、Firestore から届く前から手元に表示する

### セクションの所属

付箋・テキストの中心がセクションの範囲内にあれば、そのセクションに所属する（`parentId`）。付箋・テキストを動かしたとき、セクションの作成・移動・サイズ変更のときに決め直す。セクションを動かすと所属している付箋・テキストも一緒に動く。セクションを削除しても中の付箋・テキストは残す（所属が外れるだけ）。

### テキスト

背景のない文字で、お題や見出しに使う。FigJam と同じく、置いたときは文字の長さに合わせて横に伸びる（Enter で改行）。日本語の長い文を貼り付けても画面の外まで伸びないよう、幅には上限（800px）を設け、超えたら折り返す。右端の取っ手をドラッグすると「幅を決めた」状態になってその幅で折り返し、取っ手をダブルクリックすると文字に合わせて伸びる状態に戻る。高さは文字の量で決まる。空のまま編集を終えると削除する（見えないテキストを残さない）。表示の重なり順は付箋と同じ層で、z の順に並ぶ。

### スタンプの付け先

スタンプは押した位置（またはドラッグで置き直した位置）の中心にある付箋、なければセクション、なければボードに付く（`targetId`）。付箋の縁を少しはみ出しても付くよう、付箋の外側 `STAMP_ATTACH_MARGIN`（16px）までは付箋に付く扱いにし、2枚の付箋のすき間では近い方に付ける（`findStampTarget`）。スタンプツールの使用中やスタンプのドラッグ中は、付く先の付箋を青く光らせて、どこに付くかを押す前にわかるようにしている。CSV ではどの付箋にも付いていないスタンプの数を説明の行に書き、数え漏れに気づけるようにしている。付け先からの相対位置で持つので、付箋やセクションを動かすとスタンプも一緒に動く。付け先が削除されるとスタンプも表示されなくなり、元に戻すと一緒に戻る。

### 矢印

付箋などを2つつなぐ矢印（`type: 'connector'`、`src/board/Connectors.tsx`）。業務フローや因果関係の整理に使う。

- 位置は持たず、両端（`fromId` → `toId`）の中心を結ぶ線を、それぞれの縁の少し外（`CONNECTOR_GAP`）で止めて描く（`connectorLine`）。両端を動かせば矢印もついてくるので、ドラッグ中に矢印を書き換える必要がない
- 片方の端が削除されたら表示しない（矢印は消さない）。スタンプの付け先と同じ考え方で、付箋を消して元に戻すと矢印も一緒に戻る。CSV・コピーでも両端がそろっている矢印だけを扱う
- 線は SVG の層（画像より手前、付箋・テキストより奥）に描き、ラベルは HTML で線の真ん中に置く。細い線でも押しやすいよう、見えない太い線（16px）で押した場所を受け取る
- 引き方は2つ。どちらも同じ処理（`src/board/connectDrag.ts` の `beginConnect`）
  - ツールバーの「矢印」（L キー）：付箋・テキスト・画像を押して、ドラッグして離すか、クリックしてから矢印の先をクリックする（クリックなら、途中でスクロールや拡大・縮小をして遠くの付箋にもつなげる）。押せるものにはマウスを乗せると枠が出る。引き終えても矢印のツールのまま（フローを整理するときは何本も続けて引くため。スタンプ・コメントのツールと同じ）。選んでいる間は画面の下に「矢印の始まりをクリック（Escで終了）」、クリックで伸ばしている途中は「矢印の先をクリック（Escでキャンセル）」と出す
  - クリックで伸ばしている途中は、Esc・元のものをもう一度クリック・何もないところをクリックのどれでもやめる（ツールは続く）。もう一度 Esc を押すと選択のツールに戻る。途中は、離すとできるものは出さず、カーソルまで矢印を伸ばすだけ
  - 付箋を選ぶと出る「＋」をドラッグする（伸ばしている間は「＋」を隠す）
- セクションは矢印の始まりにも先にもならない（`isConnectable`）。ボードはセクションで区切って使うことが多く、セクションの中の余白を押したり離したりしたときにセクションにつながってしまうため。中の余白は「何もないところ」として扱う。前からセクションにつないである矢印は、そのまま表示する
- ドラッグ中は点線の矢印が伸び、離した位置で一番手前に見えているもの（付箋・テキスト → 画像、`boxAt`）につながる。何もないところで離すと、元と同じ種類のもの（`connectedLook`）を作ってつなぐ：付箋からは同じ色・形の付箋、テキストからは同じ大きさ・色のテキスト（Miro と同じく、元と同じ種類）。画像からは作らない（画面遷移図では、先の画面も画像として貼ってあるため）。元に戻すは1回で両方消える。離す前から、できるものを半透明で出す。できるものは、伸ばした向きの手前の辺がカーソルの位置に来るように置き、元との間は `CONNECT_MIN_GAP`（96px）以上あける（`connectedStickyRect`。矢印が見えるよう、「＋」を押して隣に足すとき（24px）より広い）。テキストは、空のときに出る「テキスト」の幅で置き、作ったらすぐ表示された大きさを保存する（矢印の先を文字に合わせる）。「＋」を押すだけなら今までどおり隣に付箋を足す。ほかに、2つ選んで操作パネルの「矢印でつなぐ」（先に選んだ方から）
- 「＋」から伸ばしている先は、元の付箋の中心の線にそろえる（`alignToSource`）。Shift を押している間は真横か真下に固定し、押していなくても中心の線から画面上で 12px 以内なら吸い付く（⌘ / Ctrl で吸い付かない）。何もないところで離すと、元の付箋と中心がそろった位置に付箋ができる
- 向きは、矢印を選ぶと出る3つのボタンで選ぶ。横に近い矢印は「→ ← ↔」、縦に近い矢印は「↓ ↑ ↕」で、画面で見たままの向き（→ は右側のものに矢じりが付く）にする（`connectorDirection`）。どちらから引いたかを意識しなくてよいように。→ と ← はつなぎ元とつなぎ先を入れ替えて表し、↔ は `bothEnds: true`。今の向きのボタンを選ばれた表示にする
- 同じものどうしはつながない（ルールでも拒否）。同じ向きの矢印がすでにあるときは作らない
- 範囲選択と ⌘A では、両端がどちらも選ばれたときに矢印も選ぶ。動かすときは矢印そのものは動かさない
- コピーは、両端を一緒にコピーするときだけ矢印も入れる（矢印を選んでいなくても入る）
- CSV の「つなぎ先」の列に、つないだ先の行の番号を「番号（テキスト）」の形で書く。両向きの矢印は両方の行に書く。表にない先（セクション・画像）は書かない

### コメント

付箋に付けるコメント（`src/board/comments.ts`・`CommentPanel.tsx`）。ボードの好きな場所にピンを立てる形にはせず、付箋に付ける（CSV の付箋ごとの行に入れられ、AI に渡すときも「付箋＋その意見」として扱えるため）。

- 返信の入れ子・「解決済み」・通知（@メンション）はなし。付箋ごとに古い順に並べるだけ
- コメントがある付箋の右上に件数（💬 3）を出す。押すか、付箋の操作パネルの「コメント」で、付箋の横にパネルが開く（右に入らなければ左）。Enter で送信、Shift＋Enter で改行
- ツールバーの「コメント」（C キー）：スタンプと同じく続けて使えるツール。指した付箋を光らせ、押すとその付箋のパネルを開く。付箋以外を押すとパネルを閉じる
- 本文の編集は書いた本人だけ（他人が直すと、その人の発言として見えてしまうため）。削除は本人とボード作成者。どちらもルールで守る。削除は消した印を付けるだけで、元には戻さない
- コメントの送信・編集・削除は、ボードの「元に戻す」には入れない（発言を戻すと会話が混乱するため）。削除するときは確認を出す
- 付箋を削除するとコメントも一緒に見えなくなり、元に戻すと一緒に戻る（スタンプと同じ。コメントのデータは消さない）。「元に戻す」で戻せるのは消した本人だけなので、コメントが付いた付箋を消すときは件数を出して確認する
- 画像の書き出しには件数の表示だけが写る（中身は CSV で見る）

### 文字の中の URL

付箋とテキストの文字の中の URL は、表示するときだけ押せるリンクにする（`src/lib/links.ts`・`src/board/LinkedText.tsx`）。投票ボードの説明に参考のページを貼るなど、ボードから別のページへ案内するため。データは文字のままで、編集中はふつうの入力欄に戻る。

- リンクにするのは `http://`・`https://` で始まるものだけ。`javascript:` などは文字のまま表示する（押すとプログラムが動いてしまうため）。`new URL()` で解釈し直してから使い、見た目の似た文字のドメインは実際の宛先（`xn--`）の形で開く
- 「（https://…）」「https://…。」のように日本語の文の中に書いても、後ろのかっこや句読点は URL に含めない
- 表示する文字は URL そのもの（「こちら」などの言葉に置き換えない）。押す前に行き先が見えるようにする
- 新しいタブで開き、`noopener noreferrer` で、開いた先から N-Board のタブを操作させず、どのボードから来たかも伝えない
- 付箋・テキストの選択と移動はそのまま行う。押してから動かした（ドラッグした）ときや Shift＋クリックでは開かない。スタンプ・コメントなどのツールを選んでいるときも、そのツールの操作を優先して開かない
- ダブルクリック（文字の編集）の1回目で開いてしまわないよう、押してから 250ms 待ち、2回目が来なかったときだけ開く
- リンクのドラッグでブラウザが URL を運ぶ動きはさせない。画像の書き出しには下線付きの文字として写る。CSV は文字のまま

### コピー＆ペースト

選んだ付箋・セクション・テキスト・画像を ⌘C（⌘X）でコピーし、⌘V で貼る（`src/board/clipboard.ts`）。同じボードの中の複製と、ボードからボードへの移し替え（ローカルで作ったボードを本番に移す、前のふりかえりの枠を使い回すなど）の両方に使う。

- コピーしたものは、パソコンのクリップボードに HTML の属性（`data-nboard-objects`）として入れる。別のタブ・別の環境（ローカルと本番）の N-Board にも貼れる。あわせて文字だけの形も入れるので、Slack などに貼るとセクション名・付箋・テキストの文字が1行ずつ並ぶ
- セクションをコピーすると、中の付箋・テキスト・画像も一緒に入る。付箋に押されたスタンプ（みんなの投票・反応）とコメントは入れない。スタンプそのものを選んだときだけ入れる
- 貼るときは全体の真ん中をマウスの位置に置き、並びはそのまま（マウスがボードの外やツールバーの上にあるときは画面の真ん中）。文字・画像を ⌘V で貼るときも同じ位置に貼る。同じ場所に続けて貼ったときは 24px ずつずらす。ID は付け直し、セクションと中身・スタンプと付け先のつながりは保つ。作成者は貼った人になる
- 貼るデータはよそから来たものとして扱い、1つずつ形（種類・色・文字の長さ・大きさ・画像の置き場所）を確かめて、決まった項目だけを取り出す。一度に 500 個まで
- 画像は、別のボードからのときはファイルをこのボードの置き場所に写してから作る（Storage のルールで、元のボードを開ける人しか読めない）。写すのは自分が開いたことのある（履歴にある）ボードの画像だけ。よそで作られたデータに「自分しか開けないボードの画像の置き場所」を書かれ、それを貼ったときに、その画像をほかの人が見られるボードへ写してしまわないようにするため。写せなかった画像は貼らずに知らせる
- 元に戻すは1回でまとめて戻る。文字を入力中や、文字を選んでいるときの ⌘C・⌘V はいつもどおり

### 複製（⌥＋ドラッグ・⌘D）

- ⌥（Alt）を押してドラッグを始めると、動かし始めた瞬間に選んでいるものを同じ位置に複製し、そこからは複製の方を動かす。元はその場に残り、吸着の相手になる（元と縦横をそろえて置ける）。Shift を押せば縦か横に固定できる（移動と同じ）。動かさずに離したら何もしない
- ⌘D（Ctrl+D）と操作パネルの「複製」ボタンは、少し右下（`PASTE_CASCADE`）にずらして複製する。タッチ操作でも使えるようにボタンも置いた
- 何を複製するかは ⌘C と同じ（`collectForCopy` → `planDuplicate`）。セクションの中身と、一緒に複製するもの同士の矢印も入れる。付箋に押されたスタンプ（投票）とコメントは入れない（票が増えないように）
- 元に戻すは「作った」だけを記録し、1回でまとめて消える（⌥＋ドラッグで置いた位置は記録しない）
- 複製したあとは、複製の方を選んだ状態にする

### 付箋の形

付箋は「正方形」と「横長」の2種類から選べる（置くときはツールバーの付箋の横に開くパネル、置いたあとは付箋を選んだときの操作パネルで切り替え）。大きさを自由に変えられるようにはしない（大きさがばらばらだとボードが雑然とし、吸着や「＋」での並びもそろわないため）。

- 横長の幅は `STICKY_WIDE_WIDTH`（正方形2枚＋すき間 = 344px）。高さは正方形と同じ。正方形と混ぜて並べても横幅がそろう
- データは今までどおり `w` を持つだけ（形の項目は増やしていない）。切り替えると左端の位置はそのままで幅だけ変わり、中心が動くので所属セクションを決め直す
- 置く付箋の形はツールバーで選ぶ（スタンプと同じ、付箋のボタンを押している間だけ横にパネルを開く）。最初は正方形で、選んだ形は次に置く付箋とキャンバスのダブルクリックに使う（ページを開き直すと正方形に戻る）。「＋」では元の付箋と同じ形の付箋を足す
- ツールバーの付箋のアイコン（と形を選ぶパネル）は、次に置く付箋の色と形をそのまま表す。色は最後に付箋の色を変えたときの色（`useNextSticky`）
- 文字の大きさは、横長は広い分だけ同じ大きさで多く入るようにする
- 横長にして右の付箋と重なっても、自動ではずらさない
- 複数選んで正方形と横長が混ざっているときは、どちらのボタンも選ばれていない表示にし、押すとまとめてその形にする

### 選択と画面の移動

- 選び方：クリックで1つ、Shift＋クリックで選択に足す・外す。何もないところ（セクションの中の何もないところも含む）からドラッグすると範囲で選ぶ（Shift を押して始めると今の選択に足す）
- ⌘A（Ctrl＋A）でボード上のものを全部選ぶ。範囲選択で全部を囲んだときと同じく、付け先と一緒に動くスタンプは選ばない。文字の入力中は、いつもどおり入力欄の文字を全部選ぶ
- 範囲で選ぶもの：付箋・テキスト・スタンプは枠に少しでもかかれば選び、セクションは全体が枠に入ったときだけ選ぶ（中の付箋を選びたいだけなのに、毎回セクションまで選ばれないように）。付け先も選ばれるスタンプは選ばない（`marqueeHits`）
- 選んだものはまとめて動かせる（選んだセクションの中の付箋も一緒に動く）。削除もまとめてでき、同じ種類どうしなら色もまとめて変えられる。元に戻すは1回でまとめて戻る。大きさの取っ手と付箋の「＋」は、1つだけ選んでいるときに出す
- セクションは見出しをつかんで動かす（FigJam と同じ）。中の何もないところのドラッグは範囲選択なので、間違えてセクションを動かしにくい
- Shift を押している間は、大きく動かした方の向き（横か縦）だけに動く。離すと自由に戻る。動かしている途中で押しても、押してからドラッグを始めてもよい。Shift を押したままドラッグを始めたときは、押したものを選択に足して、選んでいるものをまとめて動かす（動かさずに離せば、ふつうの Shift＋クリックと同じく選択に足す・外すだけ）。そろえるための吸い付きは、動かせる向きだけに効く
- 選んでいるものには 3px の青い線を出す。付箋・テキスト・画像・スタンプは少し外側に、セクションは自分の枠線に重ねて1本にする（外側に出すと枠線と二重線になり、大きさの取っ手をどちらの線に合わせてもずれて見えるため）。大きさの取っ手は、どれも青い線の中央に置く。線はボードと一緒に縮むので、大きく縮小すると細く見える
- セクションの大きさは、右下の角で縦横を、右の辺で横だけを、下の辺で縦だけを変える（辺の真ん中に小さな取っ手を出し、辺のどこをつかんでもよい）。左の辺・上の辺は、位置と中身の所属も変わるので今は付けていない
- 画面の移動：トラックパッドの2本指スライド・ホイール、スペース＋ドラッグ、ホイールボタンのドラッグ、ツールバーの「画面移動」。スペース＋ドラッグはどのツールを選んでいても画面を動かす（付箋などを置くツールでも、置かずに画面を動かす）。タッチ操作では指で範囲を描くより画面を動かすほうが多いので、1本指のドラッグで画面を動かす。2本指のピンチで拡大・縮小し、2本指のまま動かすと画面を動かす（2本目の指が触れたら、1本目で始めていた操作はその位置で終える）
- 「画面移動」のツール（H キー、「選択」は V キー）：どこをドラッグしても画面を動かす（付箋の上から始めても付箋は動かさない）。付箋などをダブルクリックしたら「選択」に戻して編集を始め、戻し忘れて付箋を触れなくなるのを防ぐ。ほかの操作だけでは知られにくい移動の方法を、ツールバーを見ればわかるようにするためのもの
- 右下に「💡 スペース＋ドラッグでも画面を移動できます」のヒントを出す。消えるのはスペース＋ドラッグで実際に画面を動かしたときだけ（その人の画面では以後出さない。ブラウザに記録）。画面移動のツールで動かしても近道を覚えたことにはならないので消さない。画面移動のツールを選んだときは、1回だけ文字を濃くして目立たせる（点滅は警告のように見えるので使わない）。タッチ操作の端末では出さない

### きれいに並べる

グラフィックツールのような整列ボタンや数値の入力は置かず、動かしたときに自然とそろう仕組みだけにしている（`src/board/snap.ts`・`ArrangeAids.tsx`）。

- ドラッグ中の吸着：付箋・テキスト・セクションを動かすと（複数選んでいるときは全体の外枠で）、近くのものと左端・中心・右端（上端・中心・下端）がそろう位置に吸い付く。吸い付くのは画面上で `SNAP_DISTANCE_PX`（6px）以内のときだけで、離れていれば自由に置ける。⌘（Ctrl）を押している間は吸い付かない（以前は ⌥ だったが、⌥ は複製に使うため 2026-11-05 に変えた）
- 吸着の相手：画面に見えているもので、動かしていないものだけ（遠くのものに思わず吸い付かないように）。付箋・テキストは付箋・テキスト・セクションのどれにでも、セクション（を含む選択）はセクション同士でそろえる。スタンプは吸着しない
- ガイド線：吸い付いたことがわかるよう、薄い青の点線（2px・25%）を1本だけ出す。縦横の両方でそろったときは、より近くで吸い付いた方の線を出す。線は動かしているものとそろった相手のあいだだけに引き、拡大・縮小しても画面上で同じ太さにする。画面の座標で描くので、画像の書き出しには写らない
- 「＋」で隣に付箋を足す：付箋を選ぶと上下左右に「＋」が出て、押すと同じ色の付箋が `STICKY_GAP`（24px、点の模様の間隔）をあけて隣にでき、すぐ文字を入れられる。隣がふさがっていれば、同じ方向の空いているところに置く。できた付箋が画面の外にはみ出すときは、見えるところまでキャンバスを動かす。「＋」は付箋だけに出す。上の「＋」と重ならないよう、付箋を選んだときの操作パネルは少し上に離して出す

### タイマー

ボード全体で1つを共有し、参加者は誰でも開始・停止・+1分・終了できる。上部の中央に表示し、残り時間はタイマーの背景の色が右から減っていくことでも表す（残り 50% まで青 → 25% まで黄 → 10% まで橙 → 赤）。全員の画面で同時に動くため、プリセット（3・5・10・15分。ワークショップでよく使う時間）は時間を入れるだけで、開始は「開始」ボタンだけで行う（前回使った時間はブラウザに覚えておく。初めてのときは10分）。動いている間はアイコンと残り時間だけを表示し、操作（+1分・停止／再開・終了）は押すと開くメニューにまとめる（うっかり押して全員のタイマーを止めないため）。時間になるとゆっくり2回赤く点滅（2秒）してから、止まっている状態の表示に戻る。元に戻すの対象外。

- 動いている間の残り時間 = `remainingMs` -（サーバーの今の時刻 - `startedAt`）。`startedAt` はサーバーの時刻で記録し、ルールで `request.time` と一致することを確かめる
- 停止中は `remainingMs` に残り時間を持ち、`startedAt` は null
- 参加者のパソコンの時計のずれは、参加中の表示のハートビート（サーバーの時刻で記録される `lastSeen`）を使って補正する（`src/data/clock.ts`）
- 演出：残り3・2・1秒で画面の中央に大きな数字と「ピッ」、0秒で終了の音と付箋の色の紙吹雪（約2秒）。その瞬間を自分の画面で見ていた人にだけ出す（時間を過ぎてから開いた人には出さない）。動きを減らす設定の人には数字と紙吹雪を出さない（`src/board/TimerEffects.tsx`）
- 効果音：OtoLogic のフリー素材（CC BY 4.0）を `public/sounds` に置き、ボードを開いたときに先に読み込む。ブラウザの制限で、ページを一度も操作していない人には鳴らない（出典は `public/sounds/CREDITS.md`）

### BGM と音量

タイマーの右の🎵ボタンを押すと、BGM と音量のパネルが開く（`src/board/SoundControl.tsx`）。FigJam と同じく、どの曲を流すかはボードで共有し、聞く音量は人ごと。

- 曲を選ぶ・止める：ボード全体で共有（`state/bgm`）。参加者は誰でも変えられる。曲の ID はルールで一覧にあるものだけに限る
- 音量：効果音と BGM をまとめた1本のスライダー（自分だけ、ブラウザに覚えておく）。BGM は効果音より控えめな割合（35%）で鳴らす。0 にするとボタンが消音のマークになる
- BGM が流れている間はボタンが小さく波打つ表示になる。ページをまだ操作していなくて鳴らせない人には、ボタンに赤い印を付けて「クリックすると音が出ます」と案内する
- 再生：Web Audio のループ再生で、つなぎ目なくくり返す。全員の再生位置まではそろえない。曲の切り替え・停止は 0.6 秒でじわっと変える（`src/lib/sound.ts`）
- 音源は `public/music` の4曲（リラックス・フォーカス・ハッピー・ノリノリ）。OtoLogic の曲（CC BY 4.0）をループ用に編集した MP3（約55〜73秒、各1.3〜1.6MB）で、選ばれたときに初めて読み込む。Safari でも再生できるよう OGG ではなく MP3 を使う。MP3 はブラウザが頭と最後の余白を取り除いて読み込むので、つなぎ目は途切れない（出典は `public/music/CREDITS.md`）

### CSV の書き出し

「▾」メニューの「CSV でダウンロード」で、付箋とテキストの一覧を CSV にして保存する（参加者なら誰でも。`src/lib/exportCsv.ts`）。ブレストのあとに AI に渡したり、スプレッドシートで開いたりする用途。

- 1つのファイルで AI にもスプレッドシートにも使えるよう、先頭に「#」で始まる説明の行（ボード名・書き出し日時と、各列の意味）を付け、その下に表を続ける
- 列：番号・セクション・種類（付箋／テキスト）・文章・色・作成者・作成日時・スタンプの種類ごとの数・スタンプ合計
- 並び順：セクションをひとまとまりとして、ボードの左上から読む順（ほぼ同じ高さは同じ行として左から）。セクションに入っていないものは、置かれた位置の順で間に入る
- Excel で文字化けしないよう BOM 付き UTF-8、改行・カンマ・引用符を含む文章は1つのセルに収める。=・+・-・@ で始まる文章は数式として動かないよう先頭に「'」を付ける（「- 箇条書き」も Excel では数式になるので対象。ただの数値と「-」1文字はそのまま）
- ファイル名は「ボード名_YYYYMMDD.csv」（画像・HTML と共通。`src/lib/download.ts`）
- 列は `COLUMNS` の一覧で定義しているので、機能を追加したら列を足すだけで CSV にも入る
- コメントは「コメント数」と「コメント」（「名前：本文」を古い順に改行でつなぐ）の列に入れる。削除された付箋へのコメントは、付箋と一緒に出さない

### 画像の書き出し

「▾」メニューの「画像でダウンロード」で、ボードの見た目を PNG にして保存する（参加者なら誰でも。`src/lib/exportImage.ts`）。資料に貼ったり、ふりかえりの記録を残したりする用途。

- 画面に表示している `.world` の要素を html-to-image でそのまま画像にする。付箋などの見た目を変えても、書き出し側を直す必要はない
- 範囲は画面に見えている部分ではなく、ボードにあるものすべて（まわりに 48px の余白）。拡大・スクロールの状態に関係なく等倍で描く
- 背景は白一色（点の模様は入れない）。書き出す前に選択を外し、選択の枠・ツールバー・置き場所のプレビューなど操作用の表示は写さない
- 解像度は2倍。大きなボードは、ブラウザが作れる画像の上限（面積 16,777,216 px・1辺 16,384 px）に収まるまで自動で下げる（`imageScale`）
- 顔スタンプのプロフィール写真が外部のサーバーの都合で読み込めないときは、灰色の丸で代わりに描く
- 空の付箋・テキストの「ダブルクリックで編集」などの案内は写さない（`.placeholder`）
- html-to-image は SVG の中身（矢印の線・矢じり）に CSS を写さないので、書き出す間だけ線の色・太さなどを要素に直接書き、終わったら戻す（`withInlinedSvgStyles`）
- ファイル名は「ボード名_YYYYMMDD.png」
- 以前あった「まとめてダウンロード（画像・CSV）」は、HTML を足したときにメニューから外した（何をまとめるかがわかりにくく、複数ファイルの保存はブラウザの確認も出るため）

### HTML の書き出し

「▾」メニューの「HTML でダウンロード」で、ボードの見た目を1つの HTML ファイルにして保存する（参加者なら誰でも。`src/lib/exportHtml.ts`）。HTML を共有できるページに貼って、ボードのメンバー以外にも見せる用途。

- 画像と同じ範囲・同じ方法で写すが、PNG にせず SVG のまま HTML に埋め込む。拡大しても文字がぼやけず、⌘F で文字を探せ、付箋の中のリンクも開ける
- 1つのファイルで完結させる：貼った画像はファイルの中に入れ、外部のライブラリは使わない。書体は入れない（日本語の書体は数 MB あるため）ので、見る人のパソコンの書体で表示する（行の折り返しがわずかに変わることがある）
- 開くと全体が入る倍率で表示（100% より大きくはしない）。スクロールで移動、ピンチ・⌘＋ホイールで拡大・縮小（ボードの画面と同じ）、ドラッグで移動、2本指で拡大・縮小。上に「−」「倍率（押すと 100%）」「＋」「全体を表示」のボタン。キーは + − 0
- 上にボード名と書き出した日時を出す
- コメントは入れない（メンバー以外にも見せる用途で、途中のやりとりや名前をそのまま出さないため。中身は CSV で見る）
- 書き出した時点の写しで、あとでボードを変えても HTML は変わらない。動くスタンプは止まった絵になる
- ファイル名は「ボード名_YYYYMMDD.html」

### 参加中の表示

Firestore には切断を検知する仕組みがないため、30秒ごとに `lastSeen` を更新し、75秒以内に更新があった人を参加中として表示する。ページを閉じたときは自分のドキュメントを消す（ブラウザが落ちた場合などは時間切れで消える）。

右上の「○人が参加中」を押すと、参加中の人の一覧（アイコンと名前、自分には「（あなた）」）が開く。並びは自分を先頭に、ほかの人は名前順（顔のアイコンの並びも同じ）。表示を複雑にしないため、ボードの作成者の印やメールアドレスは出さない。人ごとの付箋の枚数も出さない（保留の「付箋の集計」を参照）。

### 使い方のページ

操作説明のページ（`public/guide.html`）を、アプリと一緒に `/guide.html` で公開している。トップ画面のヘッダー（アカウントの左）の「使い方」ボタンと、「このサービスについて」から新しいタブで開く。初めての人にも見つけてもらえるよう、メニューの中には入れずヘッダーに出す（狭い画面ではアイコンだけ）。ご意見・ご要望の連絡先（`VITE_APP_CONTACT`）は、アカウントのメニューのいちばん下と「このサービスについて」に出す。組織の紹介にもそのまま使えるよう、1つの HTML ファイルで完結させている（アイコン・スタンプの絵もファイルの中に入れ、外部のファイルは読み込まない）。ログインしなくても見られる。日本語のみ。

- キーは Mac と Windows の両方を常に書く（「command ⌘ + Z（Windows は Ctrl + Z）」）。切り替えにすると気づかれにくく、画面共有や印刷で片方しか伝わらないため
- 画面の絵はスクリーンショットではなく HTML で描いている。機能を変えたら、このページの説明も合わせて直す

### 表示の言語（日本語・英語）

画面の言葉は `src/i18n/ja.ts`（基準）と `en.ts` の辞書にまとめ、`t('キー')`（画面の部品では `useT()`）で引く（`src/i18n/index.ts`）。英語の辞書にキーが足りないと型エラーになる。

- 言語はブラウザの言語設定で決め（日本語以外なら英語）、トップ画面のアカウントのメニューとログイン画面の下で手動でも切り替えられる。選んだ言語はブラウザに記録する
- 対象：ボタン・メニュー・案内・エラーなどの画面の文言、日時の表示、CSV（見出し・説明の行・種類・色の名前）、タブの名前、アプリの説明（`VITE_APP_TAGLINE`／`VITE_APP_TAGLINE_EN`）
- 対象外：付箋やコメントなど、ユーザーが書いた内容。ボード名やセクション名の初期値（「無題のボード」「セクション」）は、作った人の言語で付ける
- 言語を切り替えても縦幅が変わらないよう、行の高さは書体に任せず `line-height: 1.5` に決めている。また、ブラウザはページの言語で日本語の代わりの書体を選ぶ（英語のページでは中国語用の書体になることがある）ため、日本語の文字の範囲だけに日本語用の書体（`N-Board JP`、ヒラギノなど）を割り当て、英字は OS の標準の書体のままにしている
- 新しい文言を足すときは、ja.ts と en.ts の両方に書く。大きなライブラリは使わず、辞書と差し込み（`{count}` など）だけの小さな仕組みにしている

### 付箋とコメントの数

ボード画面の左下（ツールバーの下）と、履歴一覧の各ボードに、付箋とコメントの数をアイコン＋数字で出す（`useBoardTotals`・`Totals`）。付箋は文字が入っているものだけを数える（置いただけの空の付箋は意見ではないため）。コメントは今ある付箋（空の付箋も含む）へのものを数え、削除された付箋へのコメントは数えない。人ごとの数は出さない（保留の「付箋の集計」を参照）。

- 履歴一覧の数は「最後に開いていたときの数」。ボードを開いている間、数が変わってから3秒待って自分の履歴（`stickyCount`・`commentCount`）に書き、ボードを離れるときにも書く。ほかの人があとで足した分は、次にそのボードを開くまで反映されない
- 履歴一覧でボードごとに付箋を数えに行くと、ボードが多いほど読み込みが重くなるため、この形にしている。常に最新にしたくなったら、Cloud Functions で付箋・コメントの作成と削除を数えてボードに持たせる
- 数を記録する前に開いたボードは、次に開くまで履歴一覧に数を出さない

### ボードの削除

Cloud Functions を使わない前提のため、作成者の画面が中身（objects・presence）を消してから最後にボード本体を消す。途中で失敗してもボード本体が残るのでやり直せる。中身だけが残ることがあっても、ルール上だれも読めない。他の人の履歴には残り、開くと「見つかりません」と表示される。

### ドメイン制限

ルールで `sign_in_provider == 'google.com'`、`email_verified == true`、メールアドレスが許可ドメインで終わることを確認している。画面側の判定とログイン時の `hd` パラメータは案内のためで、制限そのものはルールが担う。
